# 📊 Google Website Analytics

> A simple web analytics project using **Google Sites + Google Analytics 4 (GA4)** to understand website visitors and user activity.

---

## 🌐 About the Project

This project demonstrates how a Google Website can be connected with **Google Analytics 4** to monitor website performance.

The main purpose is to collect and analyze visitor information such as:

* 👥 **Unique Visitors** — How many different people visited the website
* 📄 **Pageviews** — How many times website pages were viewed
* ⏱️ **Average Visit Duration** — How long visitors stayed on the website
* 🆕 **New Users** — How many visitors came to the website for the first time

---

## 🎯 Objective

The objective of this practical is to learn how to:

1. Create and publish a website using Google Sites.
2. Create a Google Analytics 4 property.
3. Connect the website with Google Analytics.
4. Monitor visitor activity and website performance.
5. Prepare an analytical matrix using collected data.

## 📈 Analytics Matrix

The collected data is organized using the following matrix:

| Metric                    | Meaning                                 |
| ------------------------- | --------------------------------------- |
| 👥 Unique Visitors        | Different users who visited the website |
| 📄 Pageviews              | Total number of page views              |
| ⏱️ Average Visit Duration | Average time users spent on the website |
| 🆕 New Users              | First-time visitors                     |

> **Note:** Actual analytics values depend on the traffic received by the website during the selected period.
